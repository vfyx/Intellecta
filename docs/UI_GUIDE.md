# Guia visual

O Intellecta usa uma interface dark editorial com fundo preto, superfícies verde-escuro, bordas finas, lima suave e tipografia Lato/JetBrains Mono.

## Princípios

- Priorize hierarquia e leitura rápida.
- Use ações explícitas e estados vazios orientativos.
- Preserve o shell com navegação lateral, coluna central e painel de apoio.
- Reutilize cards, botões, avatares e campos antes de criar variações.

Os tokens e componentes existentes estão centralizados em [`assets/css/app.css`](../assets/css/app.css). O arquivo [`assets/css/styles.css`](../assets/css/styles.css) permanece como ponto de compatibilidade para integrações existentes.
